# 音迹（YinTrace）唱歌练习

<img src="assets/branding/icon.svg" width="88" align="right" alt="音迹图标">

音迹（英文名 YinTrace）是一个练唱歌的 App。导入一首歌，它在手机上把人声分离出来，按你给的带时间歌词，
测出每一句、每一个字的音高，画成逐字音高图；练习时实时画出你唱的音高，唱完告诉你
哪个字唱高了、唱低了、没唱出来。

用 Flutter 编写，当前只适配 **iOS**，代码结构为 Windows / macOS / Android 保留了可移植性。

## 功能

- **人声分离**：用 `UVR-MDX-NET-Voc_FT` 分离出人声；和声明显的歌可以再用 `6_HP-Karaoke-UVR`
  去掉和声，只留主唱（较慢，默认不做）。全部在手机本地完成。
- **逐字音高图**：HuBERTFA 用带时间的歌词（`[00:12.40]夜里的风慢慢吹过窗台`）逐句对齐主唱，
  再把每个字里的音符画成线条，保存在本地曲库。
- **AI 测原唱音高**：导入时用神经网络音高模型 [SwiftF0](https://github.com/lars76/swift-f0)
  （135 KB，随 App 附带，不用下载）测分离出的原唱人声，比以前的 YIN 算法准（整体准确率 92.4% 对 90.2%，
  混响下 84.1% 对 80.0%，[验证记录](docs/pitch-model.md)），结果存在本地，每次练习直接用；模型用不了时自动改用 YIN。
  取的是整首最连贯的一条旋律，主唱叠了低八度和声时也不在两个声部之间跳；混响尾巴、气声和前奏间奏里的和声不画成线。
- **演唱练习**（主打功能）：用 **YIN 算法**实时分析你唱的音高，和逐字音高图对齐显示；
  会跟着房间里的噪音调整，电器的嗡嗡声、敲击和打字声、比你小声很多的电视和说话声不当成你在唱；
  唱完告诉你哪个字唱高了、唱低了、没唱出来、不稳、抢拍或进晚了。可以单句循环练到唱准，
  不会唱的先“听这句原唱”，唱完回听自己，看每一句的得分趋势。
- **有线耳机耳返**：练习时把麦克风的声音实时送到耳机，边唱边听见自己。iPhone 上麦克风到耳机只经过
  两个约 5 ms 的缓冲（以前约 40–46 ms）；声音先压缩、限幅，最多提升 24 dB，轻声也不会被伴奏盖住，大声不会爆音。
- **中文、英文、日文歌**都能用：英文按单词、日文按假名对齐，日文汉字可以写读音。
- **校正位置和音高**：某几个字放错了位置（原唱已经唱到这个字，这里还算在前一个字上），
  或目标音识别错了，可以逐字听原唱、听目标音：调这个字开始的时间（这一句其余的字跟着重新对齐），
  升降半音或八度，或设成不计分。
- **制作成品**：把唱好的一遍配上伴奏和混响，导出 m4a，存到“文件”App 或直接分享。
- **把歌发给别人**：一首歌连同分离好的人声和伴奏、歌词和你校正过的音高图，导出成一个
  `.yintrace` 文件；对方导入后不用下载模型、不用再分离就能练。
- **自由练习**：实时音高监视器，显示音名、频率、简谱唱名和音分偏差。

界面：曲库（本地多首歌、最高分）→ 歌曲页（每句一张逐字音高图、校正位置和音高、我的录音）→ 练习页
（滚动的参考音符 + 你的实时音高轨迹 + 卡拉 OK 歌词）→ 评分（每个字的问题、单句循环、回听、制作成品）。
想先看看界面：CI 每次运行都会把测试中渲染的界面截图作为 `screenshots` 产物上传。

## 安装

- **只有 iPhone**：安装 CI 产出的测试版安装包，用自己的 Apple ID 签名，步骤见
  [只用 iPhone 测试](docs/phone-testing.md)。
- **有 Mac**：从源码构建，见下面。

### 从源码构建

需要：一台 Mac，Xcode 16 或更新版本，Flutter 3.47.9（stable），CocoaPods，一部 iOS 16+ 的 iPhone。

```bash
git clone https://github.com/zhikkz/YinTrace.git
cd YinTrace
export BOT=true CI=true FLUTTER_SUPPRESS_ANALYTICS=true ORT_DISABLE_TELEMETRY=1
flutter config --no-analytics
dart --disable-analytics
flutter pub get
cd ios && pod install && cd ..
open ios/Runner.xcworkspace      # 在 Signing & Capabilities 里选择你的开发者团队
flutter run --release            # 连接 iPhone 后运行（人声分离很吃性能，请用 release）
```

- 部署目标是 iOS 16.0（ONNX Runtime 插件的要求）。
- 第一次练习时系统会请求**麦克风权限**。
- 上面构建的是正式版。加上 `--dart-define=YINTRACE_TEST_BUILD=true` 是测试版（CI 产出的 `.ipa` 就是）：
  设置里多一组“测试版”（性能测试、只用备用线路重新下载模型、原唱音高改用 YIN 算法测来对比），
  下载模型时显示用的是哪条线路。
  正式版里没有这些代码。
- 所有插件都通过 CocoaPods 集成（`pubspec.yaml` 里关闭了 Swift Package Manager）。

## 使用说明

**建议戴耳机练习**：外放时麦克风会录到伴奏和导唱，音高检测会受干扰。

### 导入歌曲

曲库页点“导入歌曲”，页面最上面二选一（曲库还是空的时候，页面上写着要准备什么，
也可以先点“不导入，先试试自由练习”）：

- “添加新歌曲”：选择音频（mp3 / m4a / wav / flac / aiff …），填写歌名，粘贴[带时间的歌词](#歌词格式)，
  点“分离人声，生成音高图”。
- “导入yintrace文件”：导入别人发来的、或你自己导出的 `.yintrace` 歌曲文件，
  见[把歌发给别人](#把歌发给别人)。

添加新歌曲时：

- 歌词框上面有“粘贴”（直接贴上剪贴板里的歌词）和“从文件读取 .lrc”（从“文件”App 选音乐软件或歌词网站
  下载的歌词文件，UTF-8 或 UTF-16 编码；GBK 等其他编码会提示另存为 UTF-8）。替换掉原来的歌词时可以“撤销”。
- 歌词里有 `[ti:歌名]`、`[ar:歌手]` 时，自动填进歌名和歌手（你自己改过的不动）；没有时歌名用音频的文件名。
- 底部按钮还不能点时，按钮上方写着还差什么（“还差：选择音频；粘贴带时间的歌词”）。
- 首次导入需要分离人声的歌曲时，会提示下载人声分离模型（67 MB）和 HuBERTFA 逐句对齐模型（257 MB）。见[模型下载](#模型下载)。
- **“去和声”默认关闭**：这一步耗时较长（实测比分离人声还久），对多数歌作用不大，
  歌里和声明显时再打开。第一次打开它导入时，会先提示下载去和声模型（127 MB）。
- 已经是纯人声的文件，打开“这是已经分离好的纯人声”跳过分离，
  还可以另外选择一个伴奏文件用于练习。
- 处理在后台线程进行，请保持 App 在前台（屏幕会保持常亮）。进度条按实际计算量推进，显示当前阶段
  （读取 → 分离人声 →（去和声）→ 测音高 → 逐字对齐 → 保存）、模型已经跑了几次（如 37 / 118）、
  按这台设备的实测速度估算的剩余时间，以及每秒走动的已用时间，所以不会看起来像卡住。
  处理中点“取消”或返回，会先问“取消导入？”，免得误触丢掉几分钟的进度。
- 在 iPhone 上，人声分离用 GPU（Core ML）；在这台设备上和 CPU 的结果对不上或出错时，自动改回 CPU
  （[怎么检查的](docs/inference-memory.md)）。设置里的“用 GPU 加速人声分离”可以关掉。
- 采样率不是 44.1 kHz 的文件（比如 48 kHz 的 wav）也可以导入，App 会先重采样
  （[做法](docs/how-it-works.md)）。
- 导入完成后，曲库里只留分离出的人声和伴奏；你选的原文件不会再复制一份，
  选文件时系统给 App 的临时副本也会删掉。

### 查看和校正音高图

歌曲页按句列出逐字音高图：每个字是一段横线（转音时是几段；颤音、起音的上滑和句尾的下落不另算一段），
字写在线条上方，细线是原唱的真实音高曲线。

- **修改歌名**：打开歌曲页右上角的菜单，点“修改歌名”并保存，曲库会显示新歌名。
- **以前导入的歌**（包括从 `.yintrace` 文件导入的）：测原唱音高、逐字对齐和白色引导线的做法改进过
  （[做法](docs/how-it-works.md#逐字音高图)）。菜单里点“修改歌词”，不用改，直接点“重新对齐”，就会用保存的人声重新测音高、
  重新对齐、重画引导线，你校正过的位置和音高保留。
- **歌词写错了**：在菜单里点“修改歌词”，改完点“重新对齐”，不需要重新分离。没改动的句子
  保留你的校正和练习分数——在它前面加一句、删一句也一样（按歌词内容对应，不按第几句）；
  删掉或改了字的句子，分数不再保留。
- **多音字读错了**：在校正页选中字，再点“修改拼音”。例如把“长”的 `chang` 改为 `zhang`，
  保存后用 HuBERTFA 重新对齐这一句。可以填带声调的拼音，也可以选“用自动读音”撤销手动读音。
- **校正位置和音高**：点一句右边的笔（或菜单里的“校正位置和音高”），选一个字，
  可以“听原唱”“听目标音”“一起听”。
  - **位置不对**：用时间下面的按钮提前或推后（每次 0.05 秒或 0.2 秒），或者长按音高图，
    把这个字的开头直接放到长按的地方。这个时间会固定下来，这一句其余的字围绕它重新对齐，
    用 HuBERTFA 校时时只重新识别当前句。句首的字可以提前到上一句末字的拖音里，上一句末字随之缩短，
    恢复自动识别时再接回来；但不能越过上一句末字的开头。手动位置与相邻句冲突时会提示你，并保留原结果。
  - **目标音不对**：用“降八度”“降半音”“升半音”“升八度”调到和原唱一样。
  - 原唱这里听不清、是念白或和声时，打开“这个字不计分”；没测到音高的字可以“加上目标音”再调。
  - 改动马上保存，练习和打分都用改过的；“恢复自动识别”随时退回（调过位置的字回到自动对齐的位置）。

### 练习

点歌曲页底部的“整首练习”，或点某一句进入单句循环。练过以后，歌曲页上方的“先练这几句”列出上次
低于 80 分的句子（最多三句，最差的在前），点一下就循环练那一句。曲库里每首歌下面写着练过几次、
上次是哪天练的。第一次练习时顶部会提醒戴耳机，点“知道了”就不再出现。

- 播放的是去掉主唱后的伴奏（保留和声），原唱小声跟着放（导唱）。歌词右下角的“导唱：开 / 关”一点就切换：
  先跟着原唱找音，熟了再关掉只听伴奏自己唱；这个开关会记住。音量在右上角的“练习设置”里调。
- **耳返**：连接有线耳机（含 Lightning / USB-C 耳机转接头、USB 耳机），到“练习设置”打开
  “耳返（有线耳机）”。耳返音量从 50% 开始试（一般的声音和伴奏差不多响；25% 相当于以前的 100%，
  100% 再提高 12 dB），听不清再往右；伴奏太响也可以把“伴奏”调低。耳返里的声音先去掉低频、压缩轻重差别、
  压低句子之间的环境噪音，再限幅，所以轻声被托起、大声不爆音。录音和评分仍用原始麦克风声音；
  暂停、听原唱、回听和唱完时耳返静音。外放、蓝牙和 AirPlay 不开放耳返。
  打开耳返时音频会话改用测量模式（关掉系统的自动增益和人声处理），延迟更低，耳机里的整体音量可能略小。
  拔出耳机后耳返关闭，重新连接后需手动打开；每次进入练习默认关闭，只记住音量。
  （耳返音量的设置以前存成另一个值，更新后从 50% 重新开始。）
- 中间的音高图随音乐滚动，竖线是当前位置；你的声音实时画成轨迹：**石绿** = 准（默认 ±50 音分），
  **石青** = 偏低，**朱砂** = 偏高，接近时混入藤黄。唱过的字会按得分变色。
  在图上向左拖动可以往后跳，向右拖动可以往前跳。
  跟唱时圆点标出你刚唱到的音，回听时跟随录音的播放位置。纵轴放得下时不动，放不下时才放大，短暂间奏时保留刚唱过的音域，
  即使你和原唱相差一个八度，也能在同一张图上对照；麦克风偶尔测错的一个音不会让纵轴跳。
  顶部显示目标音、你的音和偏差（高/低多少音分）；两个音之间（左边显示“下一个”）不判准不准。
- 歌词上面一行写着唱到第几句（共几句）。一句开始前 3 秒有三个点倒数，一秒灭一个；
  前奏或间奏还有 5 秒以上时，右边有“跳过前奏 / 跳过间奏”，跳到这一句前 3 秒。
  一句唱完 0.6 秒后，歌词就换成下一句（间奏里看的是接下来要唱的，“听这句原唱”放的也是它）；
  这时“重唱这一句”和“单句循环”仍是刚唱完的那一句，“下一句”是接下来要唱的那一句。
- **上一句 / 下一句 / 重唱这一句**：跳到某一句前面一秒多，歌词马上换成这一句（即使上一句的尾音还在响），
  暂停时也能连着点“下一句”一句一句往后跳；第一句没有“上一句”，最后一句没有“下一句”。
- **单句循环**：歌词上面显示“单句循环 · 第 N / M 句”和“退出循环”，下面记着这一句每一遍的得分
  （如“这一句唱了 4 遍：62 → 70 → 78 → 85”），歌词一直是正在循环的这一句。
- **听原唱**：歌词下面的“听这句原唱”（或评分页每句旁边的人像按钮）把这一句连同原唱人声放一遍，
  不计分、不录音；放的时候歌词显示的就是这一句，放完回到这一句开头暂停，点播放就可以跟着唱。
- **评分**：点右上角的“评分”或唱完整首，会看到总分、每句得分，以及“先练这几个字”
  （偏高 / 偏低 / 没唱出来 / 不稳 / 抢拍 / 进晚了）。点其中一个字或任意一句，就进入那一句的循环练习。
  有低于 80 分的句子时，最上面的按钮是“先练第 N 句（S 分）”（分数最低的一句）；下面还有“从头再唱一遍”。
  单句循环时看评分，按钮是“继续练这一句”和“不循环了，回到整首”。
- **单句循环、重唱这一句**只算这一句：播放会从这一句前面一秒多开始，这段前奏（以及循环时句尾后面的
  一小段）里出现的上一句、下一句的字不计分，也不会盖掉你之前唱的录音。每句的分数和录音一样，
  保留到你再唱这一句为止：循环某一句、拖动进度条，都不会清掉别的句子。
- **回听**：评分页点“回听这一遍”，或点某一句旁边的耳机只听这一句。播放的是你刚才唱的
  （按延迟补偿放在你听到伴奏的位置）加伴奏，原唱静音，音高图显示你当时的音高线；
  回听时麦克风不计分。点“回到练习”继续练。录音只在内存里，点“制作成品”才会保存；
  唱了 20 秒以上（按测到你声音的时间算，不到 80 秒的短歌是四分之一）还没保存就离开练习页时，会先问“保存刚才唱的录音？”，
  点“保存”会放进歌曲页的“我的录音”。别的时候返回（包括 iPhone 的侧滑返回）不会多问。
- **练习记录**：查看评分、唱完或离开练习页时保存（不用先看评分）。只放着听、一直没测到你声音的那一遍不算练习，
  不记录、不计次数。一次练习是一条记录：中途看几次评分都只更新同一条；
  整首唱完再从头唱、改成循环某一句（或换一句循环），才算新的一次。唱了八成以上（按音符时长）
  才算一次整首练习，计入最高分和得分趋势；没唱完的和单句循环只记每一句的分数。
- **得分趋势**：歌曲页显示最近 20 次整首练习的得分走势；每一句的分数旁有一条小折线，
  是这一句最近 10 次的得分（包括单句循环），练一句有没有进步一眼就能看到。
- **被打断时**：切后台、锁屏、来电，或拔掉耳机、蓝牙断开时暂停播放和采集（免得突然从扬声器外放），
  返回后点播放继续；插上耳机、系统调整音频线路时继续播放。练习、自由练习采集时和成品试听播放时
  屏幕保持常亮。
- **延迟**：App 会读取系统报告的输入/输出延迟并自动补偿；如果你的轨迹总比参考线偏右（晚），
  在设置里把“延迟补偿”调大（蓝牙延迟因设备和连接方式而异，需要实测）。iPhone 上的自动补偿现在与实际一致了
  （以前少算了约 23 ms）：以前为此手动调大过“延迟补偿”的，更新后如果轨迹偏左，就把它调回来一些。
- **环境噪音**：App 跟随房间的背景噪音调整门限：比背景响得多、有清楚音高、持续 30 毫秒以上的声音才算你在唱
  （判断期间先记下，确认后按原来的时间画出来，不会晚）；敲击、打字的余响，长时间音高纹丝不动的嗡嗡声，
  比你最近唱的低 22 dB 以上的声音（离得远的电视、别人说话）都不算。离麦克风近、音量和你差不多的别人的声音还分不开，
  练习时尽量安静、用耳机自带的麦克风效果最好。

### 制作成品

评分页点“制作成品”，这一遍唱的会保存为这首歌的“我的录音”，并打开成品页：

- 边听边调人声、伴奏、混响和人声对齐（±300 ms）。
- 选整首歌或只要唱了的部分，或者只要人声（只要人声配整首歌时，导出的人声和原曲一样长，
  在别的 App 里能直接和伴奏对齐）。
- 点“导出成品”：在后台合成和编码（AAC 256 kbps，m4a），保存在“文件”App 的
  我的 iPhone › 音迹 里，并弹出系统分享面板（存到别处、隔空投送、发给朋友）。

歌曲页的“我的录音”可以再次导出或删除。戴耳机录的成品最干净。

### 把歌发给别人

歌曲页右上角菜单里点“发给别人”，再点“导出歌曲文件”，这首歌就做成一个 `歌名 - 歌手.yintrace` 文件，
保存在“文件”App 的 我的 iPhone › 音迹 里，并弹出系统分享面板。

- 文件里有分离好的人声和伴奏、歌词，以及你校正过的位置和音高（逐字音高图和音高曲线）；
  **不包含**你的练习记录、分数和“我的录音”。
- 对方在曲库页点“导入歌曲”，在最上面选“导入yintrace文件”，点“选择音迹文件”选这个文件，
  不用下载模型、不用再分离人声就能练。导入的是一首没练过的新歌；同一个文件导入两次就有两首。
- 文件没传完或损坏了会提示让对方重新发一次（每个部分都核对 SHA-256）。

### 自由练习

曲库右上角的波形按钮打开一个实时音高监视器，显示音名、频率、简谱唱名、音分偏差和滚动的音高轨迹。
接上有线耳机后，点自由练习页右上角的耳机按钮，可以开启耳返和调节耳返音量（和练习页一样低延迟、自动压限）。
切到后台再回来时，点“继续练习”。

## 歌词格式

```
[00:12.40]夜里的风慢慢吹过窗台
[00:17.95]远处的灯一盏一盏亮开
[00:35.80]下雨了 记得带伞
```

- 每行 `[分:秒.百分秒]歌词`，时间是这一句**开始唱**的时刻（毫秒 `.123` 也可以）。
- 每个汉字（以及假名、韩文音节）是一个单位；英文按单词。标点会被忽略。
- 中文的空格和标点会分隔拼音词组。英文按单词查读音，日文按假名查读音。
- 日文的小假名、促音“っ”和长音“ー”跟前面的假名算一个单位（きょ、まっ、ラー）。
  汉字后面紧跟括号里的平假名会当作读音，例如 `心(こころ)` 和 `明日（あした）`。
  词典里找不到读音的单位依靠模型的发声和边界分数定位。
- 支持一行多个时间 `[00:12.00][01:30.00]副歌`、`[offset:+200]`、`[ti:歌名]`，
  以及标记上一句结束的空歌词时间行。
- **逐字时间** `<00:12.30>字` 为模型解码提供软时间提示。手动设置的字头时间优先。
- **带翻译的歌词**：播放器导出的双语歌词里，原文和译文是时间相同的两行。时间相同的几行里，
  写在最前面的一行是要唱的，后面的当作它的翻译：不对齐、不计分，在歌曲页和练习页显示在这一句下面。
  导入页会写明有几行被当作翻译。如果译文写在原文前面，请把两行对调。

## 模型下载

用到时 App 会提示下载所需模型。下载支持断点续传，完成后校验 SHA-256。

| 用途 | 模型 | 下载的文件 | 大小 | 什么时候下载 |
|---|---|---|---|---|
| 人声分离 | UVR-MDX-NET Voc FT | `UVR-MDX-NET-Voc_FT.onnx` | 67 MB | 第一次导入整首歌时 |
| 去和声 | 6_HP-Karaoke-UVR | `6_HP-Karaoke-UVR.pth` | 127 MB | 第一次打开“去和声”导入时 |
| 逐句对齐 | HuBERTFA v0.0.7 | `1218_hfa_model_new_dict.zip` | 257 MB | 首次分离人声导入或选择重新对齐时 |

- 分离模型先从 `hf-mirror.com`（Hugging Face 镜像上的同名文件）下载；连不上、太慢或出错时，自动改用
  UVR 在 GitHub 上的官方模型库，已下载的部分接着续传，两条线路都失败才报错
  （[什么时候换线路](docs/how-it-works.md#模型下载)）。
- HuBERTFA 优先从 `ghfast.top` 下载原版压缩包，失败时自动改用上游的官方 GitHub Release。
  安装后模型和词典共占约 419 MB。
  也可以在下载窗口点“已有模型文件？从‘文件’里选”导入所需的上游原版模型文件。
  [HuBERTFA v0.0.7](https://github.com/wolfgitpr/HubertFA/releases/tag/v0.0.7)
- 模型保存在 App 的 Application Support 目录，不参与 iCloud 备份；可以在设置里删除以腾出空间，
  已经导入的歌不受影响。
- 导入纯人声可离线完成：已安装 HuBERTFA 时使用模型，否则用音高轨迹对齐。导入时 HuBERTFA 运行失败也会自动改用音高轨迹。导入已有音高图的 `.yintrace` 文件后可以直接练习。
- 测音高的 SwiftF0 模型（135 KB，MIT 许可）不在上面的表里：它随 App 附带，不需要下载，
  [做法和验证](docs/pitch-model.md)。
- 分离模型的权重文件不在这个仓库里，也不打包进 App。人声模型安装时只改 6 个字节，把时间轴改为动态；
  去和声模型是 PyTorch 权重，App 按内置的配方在手机上拼成 ONNX 模型，不需要 PyTorch。
  做法见 [assets/models/README.md](assets/models/README.md)，分段大小、内存和与 UVR 的对照见
  [推理速度、内存与验证记录](docs/inference-memory.md)。
