音迹的第一个正式版。导入一首歌，在手机上把人声分离出来，按带时间的歌词画出每个字的音高；
练习时实时画出你唱的音高，唱完告诉你哪个字唱高了、唱低了、没唱出来。
所有处理都在手机上完成，你的歌和录音不会上传。

## 安卓安装包更新（11 月 26 日）

安卓安装包重新构建过，修好了“导出成品”和“导出歌曲文件”：原先的包把文件写进音迹自己的存储，
提示“已保存”，可在手机上哪里都找不到。现在导出后会弹出系统分享面板，也可以点“存到手机”
自己选位置保存。音迹不再留着导出的文件，原先的包留下的那些（本来也找不到）会在打开 App 时删掉，
曲库和“我的录音”不受影响。

版本号还是 1.0.0，用同一把密钥签名：下载新的安装包直接覆盖安装即可。iPhone 安装包没有变。

## 安装

- **安卓**：下载 APK 后打开安装，系统提示时允许浏览器或文件管理器“安装未知应用”。
  以后的版本用同一把密钥签名，可以直接覆盖安装，曲库和已下载的模型都会保留。
  第一次练习时会请求麦克风权限，请允许。
- **iPhone**：安装包没有签名，需要用 AltStore、Sideloadly 等签名工具，以你自己的 Apple ID
  签名后安装，免费 Apple ID 就可以。免费 Apple ID 签的 App 7 天后要重新签名，
  覆盖安装会保留曲库。iOS 16 以后还要打开开发者模式。详细步骤见
  [只用 iPhone 测试](https://github.com/zhikkz/YinTrace/blob/main/docs/phone-testing.md#安装包)。

第一次导入整首歌时，App 会提示下载人声分离模型（67 MB）和逐句对齐模型（257 MB），只需一次，
建议连 Wi‑Fi；打开“去和声”时还要下载去和声模型（127 MB）。

## 主要功能

- 人声分离：用 Ultimate Vocal Remover 的模型在手机上分离人声和伴奏，可选去掉和声。
- 逐字音高图：按带时间的歌词逐句对齐原唱，用 SwiftF0 测出每个字的音高。
- 演唱练习：实时显示你唱的音高并评分，单句循环，升降调，回听自己。
- 中文、英文、日文歌。
- 校正位置和音高：逐字调整开始时间、升降半音或八度。
- 制作成品：把唱好的一遍配上伴奏和混响导出。
- 把歌发给别人：导出 `.yintrace` 文件，对方导入后不用分离就能练。
- 自由练习：实时音高监视器。
- 关于页：查看版本、检查更新（每天自动查一次，有新版本时只显示红点）、源代码和开源许可。

## 已知情况

- 安卓是第一次发布：已在 Android 14 模拟器上自动测试了 m4a 解码和麦克风授权，
  还没有在各种真机上全面验证。遇到问题欢迎反馈。
- 安卓上分离出的人声和伴奏存为 WAV，比 iPhone 上的 AAC 占用更多空间；
  安卓不能导入 aiff 和 caf 格式。
- iPhone 版没有上架 App Store，需要自己签名安装。
